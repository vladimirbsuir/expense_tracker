A comprehensive RESTful expense tracking system built with Spring Boot that helps users manage their personal finances, track expenses, set budgets, and analyze spending patterns.

</div>

## ✨ Features

- **💸 Expense Management**: Full CRUD operations for income and expense tracking
- **🗂️ Category System**: Organize transactions with customizable categories
- **💰 Budget Planning**: Set and monitor spending limits by categories
- **📊 Analytics & Reports**: Get insights with various financial reports
- **🔔 Smart Reminders**: Schedule and manage payment reminders
- **📁 Data Portability**: Import/export data via CSV files
